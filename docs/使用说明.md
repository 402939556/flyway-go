# 使用说明

库路径：`github.com/linsu/flywaygo`。

其他 Go 项目还没发版时，用本地路径：

```go
require github.com/linsu/flywaygo v0.0.0

replace github.com/linsu/flywaygo => ../flyway-go
```

发版后：

```bash
git tag v0.1.0
git push origin v0.1.0
```

```bash
go get github.com/linsu/flywaygo@v0.1.0
```

私有仓库设置 `GOPRIVATE`，并配好 Git 凭据。不改业务代码时，只交付编译出的 `flywaygo` 可执行文件。

脚本、配置、命令行和失败处理见仓库根目录 `README.md`。
